# ADR-003: Sin procesamiento de PDF en el MVP

- Estado: aceptada
- Fecha: 2026-07-27

## Decisión

OpposTest no leerá PDF, no hará OCR y no integrará IA en el MVP. Recibirá bancos JSON ya preparados.

## Motivo

Reduce drásticamente la complejidad y evita que la fiabilidad del estudio dependa de una extracción automática variable.

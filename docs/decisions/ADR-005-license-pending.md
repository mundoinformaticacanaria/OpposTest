# ADR-005: Licencia pendiente

- Estado: pendiente
- Fecha: 2026-07-27

## Contexto

El repositorio será público, pero aún no se ha decidido entre una licencia copyleft fuerte u otra licencia de software libre.

## Decisión temporal

No publicar una licencia hasta tomar una decisión expresa. Antes de la primera versión pública utilizable debe resolverse este ADR.

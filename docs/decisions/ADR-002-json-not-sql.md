# ADR-002: JSON como formato de intercambio

- Estado: aceptada
- Fecha: 2026-07-27

## Contexto

Las preguntas se extraerán previamente de los PDF mediante una IA externa.

## Decisión

Utilizar JSON versionado en lugar de SQL.

## Consecuencias

- validación segura antes de importar;
- independencia del motor de base de datos;
- facilidad de generación por IA;
- mayor portabilidad.

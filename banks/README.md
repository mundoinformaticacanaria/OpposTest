## Descargar e importar

1. Abre el archivo deseado y pulsa **Download raw file** o **Descargar archivo sin formato**.
2. Abre OpposTest.
3. Entra en **Datos → Carga de datos → Importar banco de preguntas**.
4. Selecciona el JSON descargado.

La importación añade el banco al contenido actual y no borra el historial ni el progreso existente.

## Procedencia

Los bancos se han preparado a partir de cuestionarios o repertorios oficiales ya convertidos al formato JSON de OpposTest. La aplicación conserva en cada pregunta sus metadatos de procedencia, cuando estaban disponibles en la fuente.

## Privacidad

Los JSON públicos no contienen datos de estudio de ningún usuario. Una **copia completa** de OpposTest es un formato diferente y debe mantenerse privada.
